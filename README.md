# Link Router

Keep work and personal browsing separate automatically.

Link Router opens links in `Normal` or `Incognito` based on your rules, so you don't need to copy URLs between windows.

## What You Get

- Auto-routing by domain or regex
- `Ignore` rules that always take priority
- Fast rule editing (search, reorder, enable/disable)
- JSON import/export (replace or merge)
- One-click tab mode switch (`Normal` ⇋ `Incognito`)

## Typical Use Cases

- Open work domains in Normal, personal sites in Incognito
- Keep multi-account sessions clean and conflict-free
- Skip routing for selected links with Ignore rules

## Setup In 30 Seconds

1. Open `chrome://extensions`.
2. Enable `Allow in Incognito` for Link Router.
3. Add rules in `Options`.

## Privacy

- Rules stay in your browser
- No forced cloud sync for routing
- Incognito permission is only used to open matched links there

Set a shortcut (for example `Alt/Option + 2`) for instant switching.
