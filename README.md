# Link Router

Link Router is a powerful browser extension designed to automate your browsing privacy. It allows you to define custom rules for URLs, ensuring they always open in the right environment—whether it's a standard tab or an Incognito window.

# 🚀 Core Features

## 1. Smart URL Routing (Regex Support)

Automate your workflow by setting up Regular Expression (Regex) rules. Link Router monitors your URL entries and automatically re-routes matching links to either Normal or Incognito mode based on your predefined logic.

Example: Automatically open all work-related sites in Normal mode and social media or testing environments in Incognito.

## 2. Instant Mode Toggle

Switching modes manually is now a single click away. Simply click the Link Router icon in your toolbar to instantly reopen the current tab in the opposite mode (Normal to Incognito or vice versa).

# 🛠 Usage Instructions

## ⚠️ Critical Step: Enable Incognito Access

For the extension to manage and open tabs in Incognito mode, you must manually grant permission:

1. Open your browser's Extensions page (chrome://extensions).

2. Find Link Router and click Details.

3. Toggle on the switch for "Allow in Incognito".

## Configuration

To set up your routing rules:

1. Right-click the Link Router icon in your browser toolbar.

2. Select Options.

3. Add your Regex patterns and assign them a destination (Normal or Incognito).

4. Save your settings to enable automatic routing.

## Recommended Keyboard Shortcuts

For a faster, streamlined experience, we recommend using these simple two-key combinations for the "Toggle Mode" action:

- Windows: Alt + 2

- macOS: Option + 2

(Note: You can customize them anytime via the browser's Extensions Shortcut settings page.)

Efficiency: Eliminate the manual process of copying and pasting URLs between windows.

Lightweight: Built to be fast and resource-efficient.
